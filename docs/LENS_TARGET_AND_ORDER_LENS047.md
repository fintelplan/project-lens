   input is not measuring.
2. A commit message is shell input: use `-F` with a quoted heredoc; never `!` inside double quotes.
   Write the message file **outside** any conditional that might skip it.
3. A synthetic rehearsal cannot reveal bytes you did not see; build the rehearsal from bytes, and
   rehearse every branch you will rely on (the `gh` search returned 0 for a term in 42 files).
4. Before trusting a zero, run a positive control.
5. A deferral ("until X exists") must carry its reopening trigger; when X ships, reopen every sibling.
6. "Done" needs a closure test — a stored prediction is not a checked one (S4: 112 stored, 0 checked).
7. A prompt's "never" line is dead text unless a gate or an output check enforces it.
8. De-identification: scan file names and metadata, not only content; scan joined text, not only lines;
   gate case-insensitively; write every step of an "all-or-nothing" change only after all have passed.
